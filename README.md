# Coop Compass 🎮

Бесплатный сайт для двух друзей с совершенно разными вкусами в играх.

Сайт: https://psycho-53.github.io/coop-compass/

## Возможности

- Каталог кооперативных Steam-игр: 18 889 игр при первом обновлении 11 ноября 2026 года (число меняется).
- Более 80 интересов: экшен, стратегии, RPG, выживание, строительство, сюжет, атмосфера, сеттинг, развлечения и другое.
- Две анкеты с реакциями «люблю», «не люблю» и нейтрально.
- Ранжирование по компромиссу: 72% веса меньшего индивидуального балла и 28% среднего.
- Приглашение по ссылке: другой человек получает анкету первого игрока, заполняет свою и видит подбор.
- Фильтры онлайн / локального кооператива, поиск, сортировка, избранное.
- Гостевой профиль сохраняется только в браузере; настоящее облачное сохранение настраивается через Supabase.

Проценты — эвристика, не вероятность понравиться. Классификации режимов и метки сообщества могут содержать ошибки.

## Каталог и обновления

Автоматическое обновление выполняет скрипт scripts/sync_catalog.py через GitHub Actions (.github/workflows/sync-catalog.yml): по средам и по ручному запуску Actions → Refresh Steam co-op catalog → Run workflow.

1. Источник режимов кооператива — https://imho.run/datasets.
2. Источник жанровых меток — https://steamspy.com/.
3. Данные записываются в data/catalog.json и публикуются на GitHub Pages.
4. Обложки и ссылки ведут на Steam. Ключ Steam API для этого не нужен.

### Атрибуция данных

Классификация кооператива и другие вычисляемые значения imho.run доступны по лицензии CC BY 4.0. Источник: https://imho.run/datasets. Лицензия: https://creativecommons.org/licenses/by/4.0/ . Игры и изображения принадлежат их правообладателям. Coop Compass не связан с Valve.

## Как подключить настоящую регистрацию

GitHub Pages не умеет хранить пароли. Для учётных записей используется Supabase Auth и таблица с Row Level Security.

1. Создайте проект: https://supabase.com/dashboard/projects.
2. В Supabase SQL Editor выполните файл supabase/schema.sql из репозитория.
3. В Authentication → URL Configuration задайте Site URL https://psycho-53.github.io/coop-compass/ и добавьте этот же URL в Redirect URLs.
4. В Project Settings → API Keys скопируйте Project URL и **публичный publishable / anon key**.
5. Откройте файл config.js в GitHub и подставьте URL и публичный ключ в поля supabaseUrl и supabasePublishableKey.
6. Подождите публикации GitHub Pages и зарегистрируйтесь через кнопку «Войти». Подтверждение электронной почты может быть обязательным.

НИКОГДА не добавляйте service_role, secret key и пароль базы данных в публичный репозиторий. Допускается только публичный publishable/anon ключ и включённая RLS.

Без настройки Supabase сайт работает с гостевыми профилями. Кнопка аккаунта показывает уведомление о том, что регистрация ещё не подключена.
