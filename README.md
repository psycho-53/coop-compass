# Coop Compass — рабочий MVP

Одностраничный статический сайт для поиска кооперативной игры **двум друзьям с разными вкусами**.

## Запуск

Откройте `index.html` двойным щелчком. Нужен современный браузер; сервер и установка зависимостей не требуются.

## Как работает

1. Первый игрок заполняет имя, желаемую длительность сессии, оценки 9 игровых составляющих (0–4) и стоп-фактор «без хорроров».
2. Второй игрок заполняет свою часть на том же устройстве **или по ссылке**. Для работающей ссылки на другом устройстве сайт нужно сначала опубликовать на HTTPS (например, GitHub Pages).
3. Сайт показывает ранжированные игры для двух человек, отдельные оценки соответствия, краткое объяснение и ссылку на магазин Steam.
4. В результатах можно отфильтровать сетевой/локальный кооператив, отсортировать, исключить уже неинтересную игру и поделиться готовыми результатами.

## Публикация на GitHub Pages

Создайте новый публичный репозиторий, **отдельный от других проектов**, загрузите `index.html` в корень репозитория. Затем: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save. После публикации сайт доступен по `https://USERNAME.github.io/REPOSITORY/`.

## Ограничения и честность оценок

- Каталог из 34 игр для ПК заполнен вручную; это **демонстрационная база**, а не полный каталог Steam.
- Оценки жанров и предполагаемое время комфортной игровой сессии — субъективные редакторские метки для MVP. Проценты — результат эвристики, а не прогноз статистической модели.
- Пока нет авторизации Steam, сопоставления купленных игр, живых цен, кроссплея, консолей, проверки требований к ПК, пользовательских оценок или динамических обновлений.
- Встроенный онлайн и локальный кооператив отличаются; **Steam Remote Play Together не считается встроенным онлайн-кооперативом**. Перед покупкой всегда проверяйте описание режима на странице конкретной игры.
- Профили кодируются в URL `#` без отправки данных на сервер; **это не шифрование и не конфиденциальная ссылка**. Не используйте настоящие имена и секреты. Скопированный URL содержит вкусы и ники обоих игроков.
- При открытии через `file://` ссылки на другое устройство не сработают: для совместного прохождения используйте хостинг.
- Защита от изменения данных и пользовательские аккаунты не предусмотрены.

Профили людей, характер и отзывы о напарниках — отдельный будущий модуль, не входящий в этот MVP.
