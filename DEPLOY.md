# Coop Compass · GitHub Pages

1. Создайте публичный репозиторий `coop-compass` у `psycho-53` с README.
2. Загрузите `index.html` и `.nojekyll` в корень репозитория (если загружаете файлы вручную).
3. Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
4. Адрес после публикации: https://psycho-53.github.io/coop-compass/

Сайт статический, без сервера и API-ключей. Каталог пока демонстрационный.
